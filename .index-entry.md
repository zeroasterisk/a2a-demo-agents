## Summary

Two minimal demo agents demonstrating A2A relay registration and message exchange.
No LLM required — pure Python / FastAPI.

## Agents

- **echo-agent** (port 9001): Echoes every message: `"Echo from echo-agent: {msg}"`
- **counter-agent** (port 9002): Per-sender in-memory counter: `"Counter for {sender}: {n}"`

## Tech stack

- FastAPI + uvicorn, httpx, a2a-relay at `http://localhost:8765`

## Key patterns demonstrated

- `POST /auth/request` + `POST /admin/approve/{token}` — relay registration
- `DELETE /admin/revoke/{agent_id}` — idempotent revoke before re-registration
- `GET /.well-known/agent.json` — A2A Agent Card
- `POST /a2a` — receive A2A JSON-RPC tasks
- `relay_target_agent_id` routing in message metadata
- Bearer auth on all relay calls

## Usage

```bash
RELAY_ADMIN_KEY=<key> AGENT_PORT=9001 python echo-agent/main.py
RELAY_ADMIN_KEY=<key> AGENT_PORT=9002 python counter-agent/main.py
```
